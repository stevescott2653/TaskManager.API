# How to Run the Task Manager Application from the Command Line

## 1. Start the Backend API

Open a terminal and navigate to the root of the API project (where Program.cs is located):

cd C:\DEV\TaskManager.API
dotnet run

The backend will start (by default on http://localhost:5077 or similar).

- **Important:** The backend uses JWT authentication only. All API requests must include a valid JWT token in the `Authorization` header.
- If you make changes to the backend code, stop the server (Ctrl+C) and run `dotnet run` again.

---

## 2. Start the Frontend (React Client)

Open a new terminal window and navigate to the client directory:

cd C:\DEV\TaskManager.API\taskmanager-client
npm install
npm run dev

The frontend will start (by default on http://localhost:5173).

- The frontend automatically sends the JWT token (from localStorage) with all API requests.
- If you are not logged in, you will not be able to access protected routes or load tasks.

---

## 3. Access the Application

Open your browser and go to:
http://localhost:5173

- **Login page:** http://localhost:5173/login
- **Register page:** http://localhost:5173/register
- **Dashboard page:** http://localhost:5173/dashboard

Test credentials for login:
- **Email:** testuser@example.com
- **Password:** Test1234!

---

**Troubleshooting:**  
- If you see "Failed to load tasks" or a 401/404 error, make sure you are logged in and the JWT token is present in your browser's localStorage.
- If you see a redirect to `/Account/Login`, ensure your backend is running the latest code and is not using cookie authentication.
- Always run `dotnet run` in the API root directory (`C:\DEV\TaskManager.API`), and `npm run dev` in the `taskmanager-client` directory.
- Restart both servers after making code changes.

---

**Note:**  
- Both the backend API and frontend client must be running at the same time for the app to work.
- For any issues, check the browser console and backend terminal for error messages.
